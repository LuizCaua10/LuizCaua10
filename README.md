Sou estudante de ADS, atualmente no 4º período, e desenvolvedor em formação. Gosto de aprender construindo: transformar uma ideia em uma aplicação funcional, organizada e fácil de usar.

Estou em busca de uma oportunidade de estágio em tecnologia para evoluir com uma equipe, aplicar o que venho estudando e contribuir com projetos reais.
